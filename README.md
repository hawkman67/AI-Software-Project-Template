# AI Software Project Template

Herbruikbare basis voor softwareprojecten met GitHub, Codex en aparte ChatGPT-code-review.

Begin bij [TEMPLATE_GUIDE.md](TEMPLATE_GUIDE.md).

De template bevat onder andere:
- Codex-routering en light/medium/high agents;
- read-only repository scout;
- source-of-truth- en scenario/derived-dataregels;
- impactanalyse en databaseveiligheid;
- issue-, branch-, PR- en reviewworkflow;
- impactgestuurde testprofielen;
- product-, architectuur-, roadmap-, observability- en handofftemplates;
- ADR-structuur.

Gebruik deze repository als startpunt. Maak per product een zelfstandige kopie; projecten blijven daarna onafhankelijk van de template.
