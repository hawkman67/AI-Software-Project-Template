# AI Software Project Template

Herbruikbare basis voor softwareprojecten met GitHub en Codex.

Begin bij [TEMPLATE_GUIDE.md](TEMPLATE_GUIDE.md).

De template bevat:
- Codex-routering en agentgedrag;
- light/medium/high issue-agents;
- read-only scout;
- product- en architectuursjablonen;
- issue-, test- en ontwikkelworkflow;
- ADR-structuur.

Gebruik deze repository als startpunt. Maak per product een zelfstandige kopie.
